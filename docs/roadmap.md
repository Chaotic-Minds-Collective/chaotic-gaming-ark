# ARK Adapter Roadmap

ARK is a later launch phase. Keep its schema and contracts compatible with the shared Core without blocking ATLAS and 7 Days to Die.

1. Confirm target Survival Evolved server build and cluster setup.
2. Verify available server events and administrative interface on an isolated server.
3. Define survivor, map, tribe and transfer mappings.
4. Implement heartbeat and player lifecycle adapter.
5. Add permission-scoped administration and idempotent reward delivery.
